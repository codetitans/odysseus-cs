# Odysseus Platform - .NET client

This repository contains full source code of the simple .NET/C# project capable of uploading log entries or events happening on a backend/desktop application - back to the remote [Odysseus Logging Platform](https://odysseus.codetitans.dev).

Once it's added as a dependency of your .NET/C# application, it has to be connected with your existing logging system and logs serialization has to be redirected to be able to process them and pass back to the server.

Official home of this package on [nuget.org](https://nuget.org/).
